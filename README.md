# Leeds United - World Cup 2026 Fixture Tracker

An interactive dashboard tracking Leeds United players participating in the World Cup 2026. The application is built with vanilla HTML/CSS/JS and is hosted on GitHub Pages.

## Tracked Players
- **Brenden Aaronson** (USA)
- **Noah Okafor** (Switzerland)
- **Ao Tanaka** (Japan)
- **Gabriel Gudmundsson** (Sweden)

## Key Features
- **Live Countdown Timer**: Real-time ticker counting down to the very next match.
- **Dynamic Timezone Conversion**: Instantly switch kickoff times between **GMT** and your **Local Timezone**.
- **Interactive Filters**: Filter fixtures by player cards or search for teams, venues, and dates dynamically.
- **Leeds Derby Highlight**: Visually spotlights head-to-head matchups between Leeds United players (e.g. Ao Tanaka vs Gabriel Gudmundsson on June 25th).
- **Match Predictions**: Save score predictions and private match notes directly on the dashboard (stored locally in your browser).
- **Glassmorphism Styling**: Highly polished dark mode UI built using custom HSL color systems, responsive grids, and subtle background glow blobs.

## Technologies Used
- HTML5 & Semantic Elements
- CSS3 (Custom Properties, Backdrop Blur, Flexbox/Grid)
- JavaScript (Vanilla ES6, LocalStorage API, Intl DateTime API)
- Google Fonts (Outfit & Plus Jakarta Sans)
- FontAwesome (Icons)
